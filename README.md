# Кафе желісінің ақпараттық жүйесі

Бұл жоба кафе желісіндегі тапсырыстарды,
мәзірді, төлемдерді және пайдаланушыларды
басқаруға арналған ақпараттық жүйені сипаттайды.

## Негізгі мүмкіндіктер

- Онлайн тапсырыс беру
- Мәзірді басқару
- Тапсырыс мәртебесін бақылау
- Төлемдерді тіркеу
- Есептер қалыптастыру
- Пайдаланушыларды басқару

## Негізгі автоматтандыру

Клиент тапсырысты онлайн жүйе арқылы қалыптастырады.
Тапсырыс автоматты түрде жүйеде тіркеліп,
асүй қызметкеріне жіберіледі.
Асүй қызметкері тапсырыс мәртебесін жүйе арқылы өзгертеді.

## Жоба мақсаты

Кафе желісіндегі тапсырыс беру процесін автоматтандыру.
